# Skill — Research a reference site

Study structure and rhythm. Jade keeps its own name, photos, menu, and palette.

## Steps

1. Read `AGENTS.md` and `PROJECT_BRIEF.md`.
2. Open the URL. Dismiss cookie or language gates with the least interaction. Do not book.
3. Record the final URL, viewport, and what is actually on the page.
4. For a services study, note only: hero, how groups are introduced, how a single offering is scanned (photo, name, time, price), and what the phone does.
5. Write `research/<site>-<topic>.md` with the sections below. Quote at most a label, never a paragraph of their marketing.
6. List what must not move onto Jade: their words, prices, photos, icons, medical claims, booking.
7. Stop. BA turns the note into scope. You do not edit `docs/design-guidelines.md` or components.

## Note template

```markdown
# Reference — [site] / [topic]

Visited: YYYY-MM-DD. URL. Viewport.

## Observed facts

## Interpretations

## Recommendations for Jade

## Do not copy

## Unresolved questions
```

## Passing the note

Tell BA the file path and which Jade routes it concerns (`/services`, category, detail). Recommendations are optional ideas, not approved design.
