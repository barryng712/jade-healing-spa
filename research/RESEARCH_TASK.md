# Research task — nhaspa.com.vn

Role: Website Researcher  
Prerequisite: `npm run verify:playwright` must succeed.

## Goal

Understand how a premium Vietnamese spa website is structured so **our** site can offer a comparable journey with **original** branding and content.

## Rules

- Observe. Do not copy.
- Do not submit forms, book, or create accounts.
- Pause ~1–2 seconds between navigations.
- Record actual URLs.
- Separate **Observed facts**, **Interpretations**, **Recommendations**, and **Unresolved questions**.
- Do not invent pages that were not visited.

## Viewports

- Desktop: 1440 × 1000
- Mobile: 390 × 844

## Pages and areas to inspect

1. Homepage
2. Primary navigation and mega-menus / dropdowns
3. About
4. Service categories
5. At least three representative service detail pages
6. Locations / branches if present
7. News / journal if present
8. Reviews / testimonials
9. Gallery / media
10. Contact
11. Footer
12. Mobile navigation and responsive behavior

## Deliverables

| File | Purpose |
| --- | --- |
| `research/website-audit.md` | Page-by-page observations |
| `research/sitemap.md` | URL map of what was actually found |
| `research/user-journeys.md` | Visitor paths |
| `research/ui-ux-analysis.md` | Layout and interaction patterns (not brand copying) |
| `research/component-inventory.md` | Recurring UI building blocks |
| `research/reference-urls.md` | Every URL visited |
| `research/screenshots/` | Desktop and mobile captures |

## Screenshot naming

`{nn}-{page-slug}-{desktop|mobile}.png`

## After research

Stop. Do not write BA requirements, Figma designs, or website code. Ask the owner to review.
